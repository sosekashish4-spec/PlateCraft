# PlateCraft — Fine Dining Restaurant

A modern fine-dining restaurant website built as a frontend project using HTML, CSS, and JavaScript.

## Features

* Responsive restaurant landing page
* Navigation bar
* Hero section
* About section with restaurant statistics
* Menu section
* Special tasting menu
* Gallery section
* Customer review section
* Interactive customer review carousel
* Reservation form
* Footer
* CSS hover effects, transitions, and responsive layouts

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Purpose

This project was developed as part of my frontend learning journey to practice website structure, styling, responsive layouts, and basic JavaScript interactivity.
